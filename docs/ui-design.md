# UI design reference

The requested Stitch MCP endpoint was used to create TenderGuard AI dashboard and tender-detail explorations. Stitch project ID: `7791174839022547778`. The screenshot artifact is [tender-detail.png](design-reference/tender-detail.png); a small preview is [tender-detail-preview.png](design-reference/tender-detail-preview.png).

## Applied visual direction

- Paper off-white page surfaces, warm brown typography and actions, and steel-blue navigation and evidence controls.
- Green is paired with a PASS/BID label and icon; red is paired with a FAIL/DONT_BID label and icon. Amber is reserved for uncertainty and upcoming deadlines.
- Dense but readable evidence tables, clear source quotes, and a persistent inspector panel on wide screens. Layout collapses for mobile.
- Thin warm borders, restrained shadows, compact metadata, and a clear responsible-AI notice.

The generated reference is inspiration for information hierarchy and layout only. It included fabricated tender facts and clause numbers, which are not product data. All tender names, quotes, dates, values, and verdicts shown in the app must come from a fixture or fetched public source and pass quote verification.

The image was generated by Stitch's `generate_screen_from_text` flow. No Stitch API key or credential is stored in the repository.
